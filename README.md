**2. [Kopi Rindang Sales Analysis](./02_Kopi_Rindang/README.md)**
*   **Deskripsi:** Analisis 182.625 transaksi dari 8 cabang coffee shop selama 2 tahun (2024–2025), dimulai dari membersihkan data mentah sistem kasir (POS) hingga membangun dashboard 4 halaman untuk mengevaluasi performa cabang, menu, dan jam ramai.
*   **Tools:** Power Query, DAX, Power BI.
*   **Highlight:** Menemukan bahwa pertumbuhan penjualan 17,1% tidak merata: cabang Bekasi turun 12,1%, sedangkan cabang baru Darmo ramai tetapi diskon 17,4% menekan marginnya ke 56,7%. Hasilnya disusun menjadi 6 rekomendasi bisnis.
